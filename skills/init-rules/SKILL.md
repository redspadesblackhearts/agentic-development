# Initialize agentic rules

1. Copy all [rules](../../rules) into the .agent folder
2. Reference the rules in the AGENTS.md
3. If there are other agent .mds (like CLAUDE.md), reference them to use the AGENTS.md
4. Keep/Copy already existing rules into the AGENTS.md, so there is s single source of truth
